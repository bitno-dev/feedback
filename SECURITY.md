# Security

Report a vulnerability in any Bitno extension privately, through [Report a vulnerability](https://github.com/bitno-dev/feedback/security/advisories/new). Don't open a public issue for it.

Please include the extension and its version, what an attacker can do, and the steps to reproduce it. Never include real passwords, tokens or keys; use made-up ones.

In scope, for example:

- An extension contacting anything its Marketplace page doesn't list.
- A file, workspace or setting making an extension run code or commands.
- A password, token or other secret reaching settings, logs, error messages or the network.

You'll get an answer within 7 days. Fixes ship as a new version of the extension, and the release notes credit you unless you'd rather not be named.
